# Drupal AI is not needed for the team's workflow for now

After testing Canvas AI with GLM and reviewing its instructions, Dejan concluded the coding agent already covers building components and placing them on pages, with more control. Drupal AI only matters later, for the client's editors working without a coding agent, such as translation drafts and alt text.

**Evidence**: Saw Canvas AI's conflicting instructions (the context block against Rule #4) and the API Explorer's limits, and drew the conclusion himself (15 October 2026).

**Implications**: Pause the planned lesson on providers and default models. If the course continues, it should be about the editor handover on the client project, not setup.
