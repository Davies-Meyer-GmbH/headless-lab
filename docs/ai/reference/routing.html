Agent or Drupal AI?

Ask where the result lives. In the Git repo: agent route. In the site's content: Drupal AI route.

Agent route: Codex or Claude Code

  • Figma to static frontend, through Figma's MCP server
  • Canvas components and SCSS in frontend/
  • Content types, fields, menus, and other config, exported
  • Import scripts that create content and can be re-run

Paid by the agent's subscription. Reviewed as a Git diff.

Drupal AI route: inside Drupal

  • Editors composing pages with Canvas AI from existing components
  • Alt text, summaries, and metadata with AI Automators
  • Translation drafts with AI Translate
  • Content suggestions while editing

Billed per token on a provider's API key. Reviewed by the editor in Drupal.

Where things are configured

API keys
Key module entities. In headless-lab they read gitignored files in keys/.
Default model per task
/admin/config/ai/settings, one default per operation type, such as chat or embeddings.
Test a request
API Explorer, /admin/config/ai/explorers
Canvas AI cost
Each request can send over 30,000 tokens of component context. Disable unused components to cut it.

Sources: Drupal AI docs, Canvas AI docs. From Lesson 1.
