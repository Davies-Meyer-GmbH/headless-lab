# Mission: Drupal AI for our Figma to Canvas workflow

## Why
A client project starts around 22 October 2026. The Drupal site and content will be ready, and the team will build Canvas components from a static frontend that was built from Figma. Dejan needs to decide where Drupal AI helps that project and where the team's coding agents should stay in charge, then explain the choice to developers who use different agents.

## Success looks like
- Can say, for any AI task on the project, whether a coding agent or Drupal AI should do it, and why.
- Can connect a provider, choose default models, and test a request in headless-lab.
- Can judge whether Canvas AI is ready for editors to build pages from our headless components.
- Can estimate what Drupal AI would cost the client per month.

## Constraints
- About one week before the client project starts.
- Explanations in English, plain, and for his own understanding, not presentation material.
- Reads on a desktop monitor.

## Out of scope
- Setting up Drupal projects; that is already done on the client project.
- Contributing to the Drupal AI initiative.
